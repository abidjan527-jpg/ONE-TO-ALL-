# One-to-All — PWA Chat Interface

Installable Progressive Web App for the One-to-All AI Gateway.

## Features
- 📱 Installable on Android (Add to Home Screen)
- 🤖 37+ AI models (GPT-4o, DeepSeek-R1, Llama 4, Mistral, Phi-4, etc.)
- 🌙 Dark theme, mobile-first
- 💬 Multi-turn conversation
- 🔒 Zero API keys — powered by GitHub Models
- 📶 Offline shell caching (via Service Worker)

## How to Use
1. Open `index.html` in a browser
2. Select a model from the dropdown
3. Start chatting

## Install as PWA
- **Android Chrome**: Menu → "Add to Home Screen"
- **Desktop Chrome**: Address bar install icon
